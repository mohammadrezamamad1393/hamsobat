# هم‌صحبت — پیام‌رسان گروهی

## اجرا در ویندوز
در پوشه پروژه، ترمینال VS Code را باز کن و اجرا کن:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

سپس `http://127.0.0.1:5000` را باز کن. برای نصب آفلاین می‌توانی از `pip install --no-index --find-links="مسیر پوشه wheelها" -r requirements.txt` استفاده کنی.

## امکانات
- حساب کاربری با نام و رمز عبور؛ رمزها به شکل هش‌شده در پایگاه داده ذخیره می‌شوند.
- پنل ادمین برای ساخت کاربر، مسدود/آزادکردن، تغییر رمز و حذف حساب.
- ساخت، بازکردن، پاک‌کردن پیام‌های یک گفت‌وگو یا حذف گفت‌وگو از پنل ادمین.
- گفت‌وگوهای جداگانه؛ پیام‌ها و فایل‌های هر گفت‌وگو در SQLite و پوشه `uploads` ذخیره می‌شوند.
- پاسخ، ویرایش و حذف پیام‌های خود؛ ادمین می‌تواند همه پیام‌ها را ویرایش یا حذف و یک پیام را سنجاق کند.
- استفاده از هوش مصنوعی برای همه با شروع پیام از `@ai`؛ کلید API از پنل ادمین قابل تنظیم است.
- ارسال فایل‌های مجاز تا ۱۲ مگابایت و ایموجی.

## اتصال هوش مصنوعی
از پنل ادمین، بخش «اتصال هوش مصنوعی برای همه»، کلید OpenAI API را وارد و ذخیره کن. سپس اعضا می‌توانند پیام خود را با `@ai` شروع کنند. اشتراک ChatGPT به‌تنهایی API را فعال نمی‌کند و استفاده از API ممکن است هزینه جداگانه داشته باشد. کلید را در کد عمومی یا گیت منتشر نکن.

## ذخیره دائمی اطلاعات
- پیام‌ها، کاربران و گفت‌وگوها در فایل `chat.db` ذخیره می‌شوند؛ خاموش و روشن‌شدن برنامه این اطلاعات را پاک نمی‌کند.
- فایل‌های ارسال‌شده در پوشه `uploads` قرار می‌گیرند.
- برای حفظ تاریخچه، فایل `chat.db` و پوشه `uploads` را حذف یا جایگزین نکن و از هر دو نسخه پشتیبان بگیر.
- اگر برنامه را روی هاست می‌بری، باید `DATABASE_PATH` و `UPLOAD_DIR` روی فضای ذخیره‌سازی پایدار باشند؛ برخی هاست‌های رایگان فایل‌ها را بعد از راه‌اندازی مجدد پاک می‌کنند.
- برای استقرار عمومی، متغیرهای محیطی `SECRET_KEY` و `CHAT_ADMIN_PASSWORD` را تنظیم کن و از HTTPS استفاده کن.
